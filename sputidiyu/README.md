# Электронный Дневник

Проект для колледжа 2 курса: Приложение, помогающее студентам поддерживать хорошую успеваемость.

## Описание

Это C++ приложение с GUI на базе OpenGL/GLFW и ImGui. Оно позволяет студентам авторизоваться (данные из веб-сайта), просматривать успеваемость, расписание и задачи.

## Структура проекта

- `src/main.cpp`: Основной код приложения
- `CMakeLists.txt`: Скрипт сборки
- `imgui/`: Библиотека ImGui для GUI
- `db.txt`: База данных пользователей (связана с веб-сайтом)

## Сборка и запуск

1. Установите зависимости: GLFW, OpenGL
2. `mkdir build && cd build`
3. `cmake ..`
4. `make`
5. `./ElectronicDiary`

## Функционал

- Авторизация через email/пароль из db.txt
- Основной интерфейс с разделами: Успеваемость, Расписание, Задачи
- Профиль с настройками и выходом

## Веб-сайт

Веб-сайт находится в папке `prcjt babek`, написан на Go. Позволяет регистрироваться и скачивать приложение.
